# Azure OpenAI Fundamentals

## What is Azure OpenAI?

Azure OpenAI provides OpenAI models through Microsoft Azure.

Organizations use Azure OpenAI to build secure AI solutions.

---

## Why Azure OpenAI?

Enterprise requirements:

- Security
- Compliance
- Governance
- Monitoring
- Private Networking

---

## Common Models

### GPT-3.5

Fast and low cost.

### GPT-4

More reasoning and accuracy.

### GPT-4o

Supports:

- Text
- Images
- Audio

### GPT-4.1

Strong coding and architecture reasoning.
