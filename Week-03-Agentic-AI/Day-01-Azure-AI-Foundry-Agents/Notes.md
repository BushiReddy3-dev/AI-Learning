# Azure AI Foundry Agents

## What is Azure AI Foundry?

Azure AI Foundry is Microsoft's unified platform for building AI solutions.

It provides:

- Models
- Agents
- Prompt Flow
- Evaluations
- Monitoring
- Safety Controls

---

## What is an Agent?

An Agent is an AI system that can:

- Understand requests
- Reason
- Plan
- Use tools
- Access knowledge
- Execute actions

Agent =

LLM
+
Instructions
+
Tools
+
Knowledge
+
Memory

---

## Agent Workflow

User
↓
Agent
↓
Reasoning
↓
Tool Selection
↓
Knowledge Retrieval
↓
Action Execution
↓
Response

## Agent Components

### Agent

Contains instructions and behavior.

### Model

Examples:

- GPT-4o
- GPT-4.1
- GPT-4o Mini

### Tools

External capabilities.

Examples:

- APIs
- Azure Functions
- SQL
- GitHub
- ServiceNow

### Knowledge

Provides enterprise information.

Examples:

- SharePoint
- Azure AI Search
- Documents

### Thread

Conversation history.

Maintains context.
