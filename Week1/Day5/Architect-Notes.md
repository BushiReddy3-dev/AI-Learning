# Prompt Engineering for AI Solution Architects

## Why Architects Need Prompt Engineering

Solution Architects can use Prompt Engineering to:

- Generate architecture documents
- Review designs
- Analyze risks
- Create project plans
- Generate technical documentation
- Create meeting summaries
- Design AI solutions

---

# Architect Prompt Pattern

Use the following formula:

```text
Role
+
Task
+
Context
+
Constraints
+
Output Format
```

---

# Architecture Review Example

```text
Act as an Azure Solution Architect.

Review the proposed architecture.

Identify:

- Security Issues
- Scalability Problems
- Cost Concerns
- Performance Bottlenecks

Provide recommendations.
```

---

# Azure OpenAI Design Example

```text
Act as a Senior AI Architect.

Design an Azure OpenAI solution using:

- Azure OpenAI
- Azure AI Search
- Blob Storage

Include:

- Architecture
- Security
- Monitoring
- Cost Optimization
```

---

# RAG Solution Example

```text
Design a RAG solution.

Components:

- Azure OpenAI
- Azure AI Search
- Embeddings
- Blob Storage

Provide:

1. Data Flow
2. Security
3. Architecture Diagram
4. Cost Considerations
```
