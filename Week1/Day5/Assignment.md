# Day 5 Assignment

## Objective

Create enterprise-quality prompts for real-world scenarios.

---

# Scenario 1: Azure Architecture Design

Prompt:

```text
Act as an Azure Solution Architect.

Design a secure enterprise AI solution using:

- Azure OpenAI
- Azure AI Search
- Azure Blob Storage

Include:

1. Architecture
2. Security
3. Monitoring
4. Cost Optimization
5. Risks

Provide the response in Markdown format.
```

---

# Scenario 2: Code Review

Prompt:

```text
Act as a Senior .NET Architect.

Review the provided API code.

Identify:

1. Security Issues
2. Performance Problems
3. Code Smells
4. Improvement Recommendations

Provide results in table format.
```

---

# Scenario 3: Meeting Summary

Prompt:

```text
Summarize the meeting notes.

Provide:

1. Key Discussions
2. Decisions
3. Risks
4. Action Items
5. Owners
6. Due Dates
```

# Scenario 4: Project Planning

# Scenario 5: Risk Assessment
